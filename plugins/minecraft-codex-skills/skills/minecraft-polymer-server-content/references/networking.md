# Polymer-specific networking

Use this skill for Polymer-specific client capability/context and synchronization APIs. Use `minecraft-fabric-server-dev` for ordinary Fabric C2S/S2C application payloads.

Client capability is descriptive input, never authority. Permission, ownership, economy, combat, and protected world mutation must still be validated from server state.

For Minecraft 1.21.8, resolve Polymer `0.13.13+1.21.8` and inspect that artifact's networking source before using exact method names from newer documentation.
